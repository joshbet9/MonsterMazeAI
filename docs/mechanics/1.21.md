## Confirmed architectural observations

The game has explicit game states including STARTING, LIVE and ENDING/IDLE handling.

The live game runs a per-tick task. The implementation explicitly updates movement-related state and kit behaviour every tick, while stage/phase timers run on a one-second cadence.

The maze generator exposes the active pattern index and controls safe-pad placement and maze-area state.

The MonsterManager owns monster spawning and movement and therefore needs to be treated as a first-class source for the AI's monster model.

The kit system is sufficiently substantial that abilities must be represented explicitly in the planner rather than reduced to generic item-use events.
